> 手工重复三次以上的活，都该交出去。

同事小李接了个活：把领导发来的三百多张照片，按"日期_部门_序号"重命名。他干了一下午，还改错了两个。第二天领导说日期格式换一下——**他又干了一下午**。

这一篇，就为了让你**永远不成为小李**。今天讲两样：**正则表达式**和**脚本小工具**。你不用学它们本身，只学怎么用一句人话让 AI 交给你。

## 一、正则是什么：文字里的"筛子"

你一定见过 `^1[3-9]\d{9}$` 这种"鬼画符"。翻译成人话只有一句："一个 1 开头、第二位 3~9、后面跟 9 个数字的字符串"——**也就是手机号**。

**正则就是一句"描述文字长什么样"的话，只不过用符号写。** 你在 Excel 里按 `Ctrl+F` 查"张三"是精确查找；正则是模糊查找的究极版——你不知道具体内容，但知道**规律**，比如"所有 138 开头的号码""所有 @qq.com 结尾的邮箱"。**能用一句规律描述出来的东西，正则一次全揪出来。** 这正是它值钱的地方：你要处理的是一批，不是一条。

![regex-sieve](/images/posts/2026-09-23-ai-66-regex-sieve.png)

## 二、天大的好消息：你根本不用学它

**正则是少数"AI 出现后学习价值直接归零"的技能。** 以前你得背符号表，现在只需会描述。那张符号表你看一眼有个印象就行，**明天忘光也没关系**——你真正要学的是下面三要素。

## 三、核心方法：描述正则的三要素

**说清这三样，AI 给的正则基本一次就对。**

- **① 抓什么（中文说具体）**：别说"抓手机号"，说"抓中国大陆手机号，11位，1开头"。越具体越好。
- **② 给正反样例（最关键，九成人会漏）**：只给"要中的"不够，必须同时给"长得像但不能中的"。比如你要抓手机号，就该给：`13812345678`、`15900001111`（要中）；`010-88886666`（座机）、`138123456789`（多一位）、`1381234567`（少一位）（不要中）。**给了反例，AI 才知道边界在哪。**
- **③ 在哪用**：VS Code 查找框 / Excel / Python 脚本 / 在线工具，写法略有差别，不说清就得来回改。

![three-elements](/images/posts/2026-09-23-ai-66-three-elements.png)

**记住顺序：抓什么 → 正反样例 → 在哪用。** 后面所有场景都套这个模子。

## 四、照抄就能用的两个场景

**场景1：从一堆乱文字里捞联系方式。** 跟 AI 说："我有一段混杂文本，夹着手机号和邮箱。请给我两个正则：一个抓手机号、一个抓邮箱，各附中文解释。（下面贴示例文本）" 用的时候注意：**两个正则要分别查**——VS Code 查找框一次只认一个正则，所以查完手机号、再换邮箱正则查一遍；想一次全捞，就交给一段 Python 按两个正则一起提取。

**场景2：手机号脱敏。** "我要把文本里所有 11 位手机号中间四位换成星号，如 13812345678 → 138****5678。请给我：①查找正则 ②替换表达式 ③在 VS Code 查找替换框的具体步骤（含是否开 .* 开关）。" **提醒：这类操作先在副本上做，原表留着。**

其余场景（日志报错行、日期统一、清空行）同一套路，照"三要素"改关键词即可。

## 五、正则在哪用？不用装任何东西

**三个地方打开就能用**：VS Code 查找框（`Ctrl+F` 点最右 `.*` 按钮，最常用）/ 在线测试网站（先验证对不对再拿去用）/ Excel 新版 `REGEXEXTRACT` 等函数（处理一列）。**强烈建议：拿到 AI 给的正则，先去在线测试网站贴几行真实数据试一试，三十秒能救你的命。**

![three-places](/images/posts/2026-09-23-ai-66-three-places.png)

## 六、升级：让 AI 写"脚本小工具"

正则处理一段文字；小李那三百张照片是三百个文件，得靠**脚本**——一个"一次性小机器人"，你给规则它干完就完事，**没有界面，就是一个文件，双击或敲一行命令就跑**。

新手最适合从四类活开始：批量重命名、按类型归类、多 Excel 合并、图片统一尺寸。

**描述脚本需求的四件套：**
- ① **在哪儿干**（哪个文件夹、含不含子文件夹）
- ② **对什么干**（哪些文件）
- ③ **干什么**（规则 + **一个改前改后完整例子**）
- ④ **怎么保命**（先备份 / 先只打印不执行 / 重名怎么办）

## 七、跑脚本前保命三件套

**脚本的威力和危险是同一件事：它一秒能改三百个文件，也能一秒毁掉三百个文件，而且批量操作通常没有撤销。** 雷打不动三件套：

- **① 先备份**：把 `D:\photos` 整个复制成 `D:\photos_备份`，三十秒换份心安。
- **② 先预演（Dry Run）**：让脚本只说不做，把"准备把 A 改成 B"全打印出来，眼睛过一遍再真跑。
- **③ 先拿五个文件试**：五个出错是小事，三百个出错是事故。

![safety-trio](/images/posts/2026-09-23-ai-66-safety-trio.png)

## 八、四个新手常踩的坑

- **坑1 正则太贪心捞多了**：说"请用非贪婪匹配"。
- **坑2 中文匹配乱**：明确"文本含中文，编码 UTF-8"。
- **坑3 脚本报错 No module named**：把报错原文贴给 AI，问"执行什么命令安装"，通常一句 `pip install xxx`（若提示 pip 不是内部命令，用 `python -m pip install xxx`）。
- **坑4 路径含中文/空格找不到文件**：说"请确保代码正确处理"，或最省事——先把文件夹挪到纯英文路径。

## 提示词模板盒子

**通用要求（每个模板前都适用）**：我是完全不会编程的新手，用 Windows，请当零基础，每步说清点哪里、输什么命令；关键位置加中文注释；给完整可运行文件，不要片段。

### 模板一：生成正则（万能模子）

```
【做什么】：从文本提取所有中国大陆手机号
【要匹配的样例】：13812345678、15900001111
【不要匹配的样例】：010-88886666、138123456789（多一位）
【在哪用】：VS Code 查找框 / Excel / Python / 在线工具（选一）
请给我：1）正则本体 2）逐段中文解释 3）在那个工具里怎么操作。
我完全不懂正则，请假设我一个符号都不认识。
```

### 模板二：批量文件脚本（重命名/分类/转换通用）

```
我要写 Python 脚本批量处理文件。
【文件夹】：D:\你的路径（含/不含子文件夹）
【处理哪些】：所有 .jpg 和 .png
【规则】：改成"日期_部门_三位序号"，日期取文件修改时间；
         部门请填固定值（如"市场部"）或给我"原文件名→部门"映射表，
         如 IMG_2231.jpg（市场部）→ 2026-08-05_市场部_001.jpg
【安全要求】：加"预演模式"开关（只打印不执行）；
         目标已存在则跳过并警告不覆盖；
         跑完打印成功/跳过/失败汇总。
请给完整文件 + 怎么装 Python、怎么运行。
```

### 模板三：脚本报错求助

```
我按你给的脚本运行报错了。
【执行的命令】：（原样粘贴）
【完整报错】：（终端红字整段粘贴，别只贴最后一行）
【环境】：Windows / Python 版本（不知可说不知）
请先用大白话讲是什么问题，再给具体解决办法，要执行的命令写完整。
```

## 速查表

| 三要素 | 说什么 | 常错 |
|---|---|---|
| 抓什么 | 中文说具体 | 只说"抓号码" |
| 正反样例 | 要中的+不要中的 | **只给正例** |
| 在哪用 | VS Code/Excel/Python | 不说，来回改 |

保命三件套：**先备份 → 先预演 → 先拿 5 个试。** 脚本四件套：**在哪儿干 / 对什么干 / 干什么(带例子) / 怎么保命。**
