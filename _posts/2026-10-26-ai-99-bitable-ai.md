> 数据躺在表里不会动，全靠你手动搬。

表单收一堆客户反馈，导出 Excel 一条条看、判断"Bug 还是建议"、手动填一列、挑紧急的复制粘贴到群 @ 人。**这活不难，难在它每天都来一遍。**

## 一、先搞懂：多维表到底是个啥

> **Excel 是一张纸，多维表是一块插座。**

纸只能放数据，插座能接东西——接表单、接 AI、接群机器人、接定时器。

| | Excel / 普通表格 | 多维表 |
|---|---|---|
| 一个格子里能放啥 | 文字、数字 | 还能放**下拉选项、人员、附件、关联另一张表** |
| 数据从哪来 | 你手动填 | **表单、机器人、其他系统自动写入** |
| 能不能自己动 | 不能 | **能设自动化：满足条件就干某事** |
| AI 在哪 | 你复制出去问 | **表里有 AI 字段，自动帮你填一列** |

![excel-vs-bitable](/images/posts/2026-10-26-ai-99-excel-vs-bitable.png)

**国内随便挑一个都行：** 飞书多维表格（免费额度大，本文举例）、钉钉多维表、腾讯智能表格、维格表 Vika、Notion Database。**长得像逻辑一样，学会飞书的其他照着找按钮。**

## 二、联动的骨架：进 → 转 → 出

不管自动化什么，都是这三段。**记住这三个字比记任何操作步骤都值。**

```
进：数据从哪来？（表单 / 手动填 / 其他系统）
     ↓
转：AI 怎么加工？（分类 / 打标 / 摘要 / 判断）
     ↓
出：结果去哪里？（发群 / @人 / 写回表 / 生成日报）
```

![three-stages](/images/posts/2026-10-26-ai-99-three-stages.png)

**新手最常犯的错误是一上来琢磨"转"研究提示词。** 但真正卡住你的**九成在"进"**：数据根本没进系统，还在微信聊天记录里、同事 Excel 附件里。**没有稳定的"进"，后面全是空谈。**

## 三、动手做：客户反馈自动分类 + 紧急件自动通知

> **进**：客户/同事通过表单提交 **转**：AI 自动判"类型"和"紧急程度" **出**：紧急程度「高」自动发群 @ 负责人

打开飞书新建**多维表格**。开始。

### 第1步：建表 —— 字段分四类，别搞混

**最容易被低估的一步**，表建歪后面越自动化越乱。铁律：**字段分四类，源、AI、人、态。**

| 类别 | 含义 | 本例字段 | 谁来填 |
|---|---|---|---|
| **源** | 原始数据，进来啥样啥样 | 反馈原文、提交人、提交时间 | 表单自动写 |
| **AI** | AI 加工结果 | 反馈类型、紧急程度、一句话摘要 | AI 字段自动填 |
| **人** | 只有人能填的判断 | 负责人、处理备注 | 人手动填 |
| **态** | 流转状态 | 处理状态（待处理/中/完成） | 人改或自动化改 |

**为什么必须分开？最大坑是"AI 和人抢同一个格子"。** 只建一个"分类"字段，AI 填了"Bug"，同事手动改成"建议"，第二天 AI 又跑一遍**把人改的覆盖回去**。**AI 产出和人的判断永远放不同字段，这条省你半年 debug。**

![four-field-types](/images/posts/2026-10-26-ai-99-four-field-types.png)

**具体建议：**「反馈类型」「紧急程度」两个 AI 字段**类型都选「单选」不选「文本」**。单选强制 AI 只从你给的选项挑；选文本它今天写"Bug"明天写"疑似缺陷（待核实）"，**后面统计全乱**。

### 第2步：进 —— 用表单收数据，别让人直接改表

点 **「表单」** 把「反馈原文」「提交人」拖进去，其余隐藏，生成链接/二维码发人。

**为什么非用表单不让人直接填表？** 三条血泪：

1. 直接改表会顺手改别人行
2. 会漏填必填项
3. 表单能设必填设选项设说明，从源头保数据干净

**数据源干净是所有自动化前提，源头省的每分钟后面花十分钟清洗。**

### 第3步：转 —— 加 AI 字段让它自动分类

表内新增一列，类型选 **「AI 字段」**（其他平台叫「智能字段」「字段捷径」，找带星或魔法棒图标），填提示词。**三句咒语照抄：**

```
【干什么】请阅读【反馈原文】，判断这条反馈属于哪一类。
【只能选】只从以下五个选一个，原样输出不解释：
功能建议 / Bug报错 / 服务投诉 / 价格咨询 / 其他
【不确定】无法判断输出"其他"，不要猜。
```

**三句 = 干什么 + 只能选 + 不确定怎么办。** 后两句是重点：没「只能选」AI 会发明分类名**统计崩溃**；没「不确定」遇到看不懂的**硬猜，猜错比留白危害大**。

同样再加「紧急程度」AI 字段：

```
【干什么】请阅读【反馈原文】，判断紧急程度。
【只能选】高/中/低，三选一，只输出这一个字不解释。
【判断标准】高：影响使用/付款失败/数据丢失/明确投诉退款；中：有问题但有替代；低：建议/咨询/夸奖。
【不确定】判断不了输出"中"。
```

**注意「判断标准」这段。** 不给标准，AI 眼里的"用户说不好用"可能就是高优先级。**你觉得理所当然的标准，AI 一点不知道。**

![ai-field-config](/images/posts/2026-10-26-ai-99-ai-field-config.png)

填完保存回表，已有行开始自动跑出结果，这就是"转"。

### 第4步：出 —— 设自动化，紧急件自动通知

点 **「自动化」→「新建自动化」**。结构永远三段：**当 → 若 → 则。**

| 三段 | 本例配置 | 说明 |
|---|---|---|
| **当**（触发） | 记录被创建 | 新反馈进来触发 |
| **若**（条件） | 且「紧急程度」= 高 | 只高优先级继续 |
| **则**（动作） | 发飞书消息到客服群 | 执行动作 |

消息插入字段变量：

```
【紧急反馈】
类型：{反馈类型}
内容：{反馈原文}
提交人：{提交人}
请负责人尽快处理。
```

![when-if-then](/images/posts/2026-10-26-ai-99-when-if-then.png)

**触发条件就四种，认全够用：**

- **新增**（表单提交/导入）
- **变更**（某字段改成某值，最常用状态改"已完成"时通知）
- **定时**（下篇主角）
- **手动**（**新手最推荐，先手动跑熟再改自动**）

### 第5步：验 —— 上线前三跑，别一次放开

1. **单跑**：手动提交 1 条，看 AI 填对没、通知到没到
2. **小跑**：找 5 条真实历史反馈丢进去，重点看**边界**——空内容、超长、纯表情、方言口语
3. **放跑**：确认无误发真实用户

**"小跑"最易被省也最容易出事。** 你造的测试数据永远干净，真实用户输入是"啊啊啊这破东西"和三千字小作文。

## 四、五个坑，我先替你踩了

- **坑1：循环触发（最坑）**。设"字段被修改→更新另一字段"，更新又触发这条，无限套娃烧光额度。**解法**：触发尽量用「记录创建」；非用「字段修改」就在「若」加排除（如"且 状态≠已处理"）。
- **坑2：通知轰炸**。一次性导入 100 条，自动化发 100 条群消息全组静音。**解法**：批量导入前**先关自动化，导完再开**，贴脑门上。
- **坑3：AI 字段花额度**。按行计费，5000 行历史加个 AI 字段可能全表跑一遍。**解法**：先 10 行测试表调顺提示词，再搬正式表。
- **坑4：空值没兜住**。用户交空白反馈，AI 面对空内容**编一个**。**解法**：表单「反馈原文」设**必填+最少字数**；自动化「若」加"且 反馈原文 不为空"。
- **坑5：自动化以谁身份跑**。默认用**创建者**身份，你离职退出群**整条静默失效没人知道**。**解法**：重要流程建在**团队空间**不建个人；表留字段记"上次成功执行时间"，一眼看出死没死。

## 五、提示词模板盒子

### 模板1：AI 字段 · 分类打标（万能骨架）

```
【干什么】请阅读【______字段】内容，判断它属于哪一类。
【只能选】只从以下选项选一个，原样输出不解释不加标点：
选项A / 选项B / 选项C / 其他
【判断标准】选项A：______ 选项B：______ 选项C：______
【不确定】无法判断输出"其他"，禁止猜测。
【禁止】禁止输出选项以外的任何文字。
```

### 模板2：AI 字段 · 一句话摘要（给人扫一眼）

```
请把【______字段】内容压缩成一句话。
1. 不超 25 字 2. 必须含"谁+遇到什么+想要什么" 3. 只用原文信息禁补充禁推测
4. 直接输出不写"摘要："前缀 5. 信息不足输出"信息不足"
```

### 模板3：让 AI 帮你设计表结构（建表前先问）

```
我要用多维表做：______（一句话）。
参与人：______ 数据从哪来：______ 最后要看什么结果：______
请设计字段，输出 Markdown 表，列：| 字段名 | 类型 | 填写方式（表单/AI/人工/自动化） | 为什么需要 |
要求：1.字段不超10个能少则少 2.明确区分"AI生成"和"人工判断"不合并一列 3.单选类直接给建议选项 4.最后告诉我哪个字段最易填错及原因
```

### 模板4：让 AI 帮你排查自动化没生效

```
我配了条自动化没按预期工作。
【想实现】______【触发】______【筛选】______【动作】______【实际发生】______（没触发/触发了动作没执行/执行了结果不对）
请按顺序排查，逐条给可能原因和验证方法：
1.触发条件真满足了吗 2.筛选是否过严（空值/前后空格/选项值不一致） 3.动作是否有权限问题 4.是否循环触发或被限流
直接给可操作检查动作，别讲原理。
```

## 六、今天记住这几句就够

| 要点 | 内容 |
|---|---|
| **多维表本质** | Excel 是纸，多维表是**插座**——接表单、AI、机器人、定时器 |
| **联动三段** | **进**（数据从哪来）→ **转**（AI 加工）→ **出**（结果去哪） |
| **九成人卡在哪** | 卡在"**进**"，不是提示词 |
| **字段四类** | **源**（原始）· **AI**（机器填）· **人**（人工）· **态**（状态） |
| **头号铁律** | **AI 字段和人工字段绝不能是同一列**，否则 AI 覆盖人的修改 |
| **AI 字段三句咒语** | **干什么** + **只能选**（锁选项） + **不确定怎么办** |
| **分类字段类型** | 选「**单选**」不选「文本」，否则统计必乱 |
| **自动化三段** | **当**（触发）→ **若**（条件）→ **则**（动作） |
| **触发四种** | 新增 / 变更 / 定时 / 手动（**新手先用手动**） |
| **上线三跑** | **单跑**（1条）→ **小跑**（5条真实看边界）→ **放跑** |
| **导入前必做** | **先关自动化再导数据**，否则通知轰炸 |
| **最阴的坑** | **循环触发**——改字段又触发自己 |

数据能自己流进来、AI 能自动加工了，还差最后一件：**它得自己按点儿干活。**

第100篇把「定时」触发器用起来——**让 AI 每天 18:30 自己写好日报发群里，你啥都不用做。** 顺便说清三件更重要的事：为什么日报真正难点**不是 AI 会不会写**；当天没人填时 AI 会编份漂亮假日报怎么兜；为什么日报**长期停在半自动**别全自动。第100篇，系列刚好一百篇，我们下篇见。
