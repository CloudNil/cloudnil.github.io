# 第28篇：让 AI 写周报/日报——模板直接抄

> 周五下午六点，办公室走空了，你还在改周报第三版。明明活儿都干完了，卡在最后这 300 字上。

**写周报难，难在三件事：**

- 忘了这周到底干了啥
- 干了的事写出来像流水账
- 写完读一遍，感觉自己一周啥也没干

上一篇讲了提示词的四要素。**这一篇，虎哥就把四要素套进周报这个最高频的场景，让你下周五 10 分钟交周报。**

---

## 一、先说清楚：AI 不能替你回忆

开头先泼盆冷水，**AI 写不出你的周报，因为它不知道你干了什么。**

网上那些"一句话生成周报"的演示，生成的都是通用废话。真正的分工是这样的：

- **你负责**：把这周干的事想起来，用大白话列出来（**5 分钟**）
- **AI 负责**：整理逻辑、组织语言、调整语气、控制篇幅（**1 分钟**）
- **你负责**：核对数字、改改措辞、提交（**4 分钟**）

**加起来 10 分钟。** 而你现在，光是盯着空白文档发呆就不止 10 分钟了吧？

**所以第一步不是打开 AI，是打开你的记录。**

## 二、5 分钟找回这周干了啥

这是很多人卡住的第一步。虎哥给你四个"记忆挖掘点"，**照着翻一遍，基本不会漏：**

- **翻工作群聊天记录** —— 从周一往后滚，看你发过什么、回过什么
- **翻日历/会议记录** —— 开过的会就是干过的事
- **翻邮件发件箱** —— 你发出去的每封邮件背后都有一件事
- **翻待办清单/工单系统** —— 已完成的条目直接抄

**翻的时候不用整理，想到就记，一行一句。** 长这样：

```
- 跟 A 客户开了两次会，合同条款基本谈定，就差法务过
- 活动方案改了三版，第三版领导过了
- 处理了十几个用户反馈，三个转给技术了
- 帮新人小王过了一遍系统操作
- 周三那个线上问题，跟技术一起查了一下午
```

**乱七八糟没关系，这就是给 AI 的原料。**

**记住一件事：宁可多列，不要少列。** 你觉得"这事太小不值得写"的，往往正是能体现工作量的东西。**让 AI 帮你判断哪些该留，比你自己删掉强。**

## 三、核心模板：把流水账变成周报

原料有了，现在套模板。

**这是虎哥用得最多的一版，直接复制改：**

```
你是一位熟悉职场汇报的资深主管，擅长把零散的工作
记录整理成条理清晰、有说服力的周报。

【我的岗位】
[填岗位，例如：市场专员]

【本周我做的事】（想到什么写什么，不用排序）
- [贴你刚才列的原料]
- [继续]

【下周计划】
- [列几条，没想好就写"待补充"]

请按以下结构输出：

一、本周完成
按重要性排序，每条一句话：做了什么 + 进展/结果。
要有具体动作和可感知的进展，不要写"积极推进""持续跟进"。

二、问题与风险
只写我上面提到的困难，我没提的不要编。没有就写"暂无"。

三、下周计划
每条具体到可执行，不要写"继续努力""保持关注"。

要求：
1. 全文 300 字以内；
2. 语气正式但不官腔，像人说话；
3. 我没提供的数据不要编造，需要填数字的地方标注[待填]；
```

**注意这里面藏着上一篇的四要素：**

- **角色** —— 资深主管
- **任务** —— 带背景的整理工作（岗位 + 素材）
- **格式** —— 三段式结构，明确到每段写什么
- **约束** —— 字数、语气、不编造

**这就是四要素在真实场景里的样子。**

## 四、看看效果差多少

用上面那份原料，AI 会给你这样一版：

> **一、本周完成**
>
> 1. A 客户合同推进至收尾阶段。本周完成两轮面谈，主要条款已达成一致，目前待法务终审。
> 2. 完成活动方案定稿。经三轮修改，第三版已通过领导评审。
> 3. 处理用户反馈 [待填] 条，其中 3 条涉及技术问题已转交技术团队跟进。
> 4. 完成新同事小王的系统操作培训，已可独立处理基础流程。
> 5. 协同技术团队排查周三线上问题，用时约半天。
>
> **二、问题与风险**
>
> A 客户合同法务审核时间不可控，可能影响签约节点。
>
> **三、下周计划**
>
> [待补充]

**对比一下你原来那份"本周完成 XX 工作，下周继续推进"。**

区别在哪？

- **每条都有动作 + 结果**，不是笼统的"推进"
- **有阶段判断**（"推进至收尾阶段"），让领导知道进度
- **不知道的数据标了 [待填]**，不瞎编
- **风险单独拎出来**，显得你有全局意识

**你要做的，就是把 [待填] 补上，把不准确的改掉。**

## 五、三种收件人，三种写法

**这是很多人不知道的一点：周报给谁看，写法完全不同。**

同一件事，对三种人要说三种话。

### 给直属领导：讲细节和卡点

他知道你在干什么，他关心的是**进度和障碍**。

**追加这句约束：**

```
补充要求：收件人是我的直属主管，他了解项目细节。
请保留具体的进度节点和遇到的卡点，
需要他协调资源的地方单独标注出来。
```

### 给跨部门同事：讲结论和影响

他不了解你的项目，**别讲过程，讲跟他有关的部分。**

```
补充要求：收件人是其他部门的协作同事，不了解我的项目背景。
请去掉内部细节，每件事用一句话说清楚：
这是什么 + 跟他们有什么关系 + 需不需要他们配合。
```

### 给大老板：讲成果和数字

他没时间看细节，**只看结果和风险。**

```
补充要求：收件人是公司高管，阅读时间不超过 30 秒。
请压缩到 150 字以内，只保留：
1. 最重要的 3 件事及其结果（有数字就用数字）；
2. 需要他决策或知晓的风险，最多 1 条。
其余全部删掉。
```

**同一份原料，切换一句约束，出来三个版本。** 这就是提示词的威力。

## 六、让周报"有成绩感"但不吹牛

最后这有个技巧，能让周报成为你的职场助力，而不是负担。

很多人写周报，明明干了不少，读起来就是平淡。**问题在于只写了"做了什么"，没写"值多少"。**

**加上这段约束试试：**

```
补充要求：在不编造任何事实的前提下，
请帮我把每件事的价值点体现出来。具体做法：

1. 有节省时间、提升效率、避免损失的，明确点出来；
2. 有阶段性进展的，说明现在处于什么阶段
   （如：从 0 到 1 / 推进至收尾 / 已交付）；
3. 涉及跨部门协作的，体现出协调工作量；
4. 严禁夸大：不许把"参与"写成"主导"，
   不许把"完成部分"写成"完成"，
   不许添加我没提到的数字或成果。
```

**最后那条是关键。** 有了它，AI 会帮你把事情说得更有分量，**但不会给你捏造功劳。**周报吹牛的下场，你懂的——**领导一问细节就穿帮。**

> 虎哥的大实话：**周报的本质不是汇报，是让别人知道你的价值。** 干了活儿不会说，跟没干差不多。但吹牛更危险。**AI 最大的作用，是帮你把真实的工作，用专业的方式说出来。**

## 七、日报怎么办

日报比周报简单，但更容易写烦。

建议的做法：**平时随手记，周五一次性生成。**

具体操作：

- 在手机备忘录建一个「本周流水」
- 每天下班前花 **30 秒**，记一两行今天干了啥
- 周五把整段贴给 AI，一次生成周报

**如果公司强制每天交日报**，用这个精简版模板：

```
把下面这段今天的工作记录，整理成一条日报。

[贴今天的流水]

要求：
1. 三条以内，每条一句话；
2. 格式：做了什么 + 到什么程度；
3. 100 字以内；
4. 不要编造，没写的不要补。
```

### 模板二：一份素材，生成三个版本（收件人切换）

```
下面是我这周的工作记录，请基于同一份素材，
帮我生成三个不同版本的周报。

【我的岗位】
[填岗位]

【本周工作记录】
- [贴原料]

请分别输出：

【版本 A：给直属主管】
他了解项目细节。保留具体进度节点和卡点，
需要他协调资源的地方单独标注。300 字以内。

【版本 B：给跨部门协作同事】
他不了解我的项目背景。去掉内部细节，
每件事说清楚：这是什么 + 跟他们有什么关系 +
需不需要他们配合。200 字以内。

【版本 C：给公司高管】
阅读时间 30 秒。只保留最重要的 3 件事及结果
（有数字用数字），以及最多 1 条需要他知晓的风险。
150 字以内，其余全删。

统一要求：
1. 三个版本基于同一事实，不许出现内容矛盾；
2. 不编造任何我没提到的数据或成果；
3. 需要填数字的地方统一标注[待填]。
```

### 模板三：给周报"提亮"但不吹牛

```
下面这份周报是我写的（或 AI 生成的），
读起来太平淡，看不出工作量。
请在不编造任何事实的前提下，帮我提升表达质量。

【原周报】
[贴进来]

【补充背景】（有就填，没有跳过）
- 这周有没有加班/救火/临时插入的任务：
- 有没有帮别人解决问题：
- 有没有避免了什么损失或风险：

请这样处理：

1. 逐条改写
   把每件事的价值点体现出来：
   - 有节省时间、提升效率、避免损失的，明确点出来；
   - 有阶段性进展的，说明处于什么阶段
     （从 0 到 1 / 推进至收尾 / 已交付）；
   - 涉及跨部门协作的，体现协调工作量。

2. 严守底线（这条最重要）
   - 不许把"参与"写成"主导"；
   - 不许把"完成部分"写成"完成"；
   - 不许添加我没提到的任何数字或成果；
   - 拿不准的地方，标注[请自行确认]。

3. 最后告诉我
   哪几处你做了"表达增强"，我好自己再核一遍。
```

**《让 AI 写工作方案/计划书》**——从一句话需求，到一份能拿去评审的完整方案。

- **为什么直接说"写个方案"永远得到废话**，正确的拆法是先要大纲再要正文

**方案写得好不好，直接影响别人怎么看你的专业度。** 这篇值得你多花十分钟。
