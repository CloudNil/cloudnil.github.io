> 记七个口诀不如记一个骨架。

第61篇"函数四要素"、63篇"接口四件套"、65篇"四张清单"……你还记得全吗？**七篇我一共给了八套方法论、四十多个要点**，攒一块就成了浆糊。这一篇不讲新东西，只干一件：把这七篇拧成一股绳——**你会发现那八套，其实是同一件事的八个变体，只需记住"母版"。**

## 一、八套方法论 = 一套骨架的八件衣服

| 篇 | 当时的方法论 |
|---|---|
| 61 函数 | 用途+输入+输出+边界 |
| 62 页面 | 定位+内容+风格+交互+技术 |
| 63 接口 | 对象+字段+动作+技术 |
| 64 数据库 | 三必备字段+四提问 |
| 65 全栈 | 数据/接口/页面/步骤四清单 |
| 66 正则/脚本 | 三要素 / 四件套 |
| 67 爬虫 | 四件套 / 三问+五底线 |

不管函数页面接口表项目，**每套都在回答五个问题**：**这是给谁用的（背景）/ 要干什么（目标）/ 喂进什么吐出什么（输入输出）/ 哪些不能做（约束）/ 给什么形式（交付）。** 它们不是八套，是一套穿了八件衣服。

## 二、万能骨架：五段式

本篇唯一要背的：

```
【背景】我是谁 / 我的水平 / 我的运行环境
【目标】我要做什么，一句话说清
【输入输出】喂进去什么，要回来什么
【约束】技术限制 + 不能做的事
【交付】要什么形式的东西
```

**口诀：背—目—进出—约—交。** 白话："我是谁，我要啥，给它什么要回什么，别越界，怎么交给我。"

**逐段要点**：
- **背景**（最被低估）：写了，AI 立刻变"手把手模式"——"我完全不会编程，Windows，请当零基础每步说清点哪里"。
- **目标**：一句话，别铺垫。
- **输入输出**（最决定质量）：**给样例 > 描述十句**。给个输入表、输出表，AI 一次就对。这是提示词性价比最高的一招。
- **约束**：防 AI 自由发挥。分技术约束（只用标准库）、边界约束（空文件跳过）、**安全约束（不改原文件、先打印清单、带预演开关——这条每次都写）**。
- **交付**：四句万能话原样抄——"完整可运行文件不要片段 / 加中文注释 / 告诉我装什么怎么跑 / 多文件说清各自放哪"。**"完整文件，不要片段"是整模块最值钱的七个字。**

## 三、逐句对照：烂提示词怎么变好

需求：合并文件夹里一堆 Excel 成总表。
- 版本0"帮我写个合并代码"→AI 全靠猜，必返工。
- 版本3（五段式）：写清背景+目标+输入(路径/结构/来源列)+输出(汇总.xlsx+来源文件名列)+约束(只用pandas、空文件跳过、不改原文件、先打印清单确认)+交付。

**这一版基本直接能用。写一次三分钟，版本0来回半小时；且 70% 可复用——背景/约束/交付下次原样贴，只改目标与输入输出。**

## 四、两个高频变形：五段式怎么"换衣服"

骨架不变，但你常遇到两种场景，套法略不同：

**变形一：改别人的代码（不是从零写）。** 把"目标"换成"在现有代码上只做 X，其他一律不动"，"输入输出"换成"贴完整原代码 + 期望改动后的行为"。这样 AI 不会手痒给你重构、顺手改了别的逻辑。

**变形二：让 AI 当陪练（不是要产物）。** 把"交付"换成"用大白话讲、出三道题考我、先别给答案"。这时候你要的不是文件，是理解——骨架照样套，只是最后一段换内容。

记住：**同一个骨架，换的永远是"目标"和"输入输出"这两段，背景/约束/交付基本不动。** 这就是它比八套方法论好记的地方。

## 五、六条通用铁律

1. **完整文件，不要片段**（说过三遍还要说）。
2. **改一处，别重写**："在现有代码上只加XX功能，其他逻辑一律不动，给完整文件"——"其他一律不要动"七字救你多次。
3. **报错贴原文，别转述**：整段复制从第一行到最后一行。
4. **先跑通，再优化**：跑通→加功能→才优化，一次一步。
5. **先小后大**：采集先3页、批处理先5文件、DELETE前先SELECT、文件操作先预演。
6. **让 AI 讲给你听**："用大白话讲这段代码流程，假设我完全不懂"——你不必看懂每行，但得知道它大概干啥。这一条和69篇"读代码"一脉相承：能跑不算完，心里有数才算。

## 六、一张地图：从需求到代码

想清楚目标，一路走到底，大致八步：
1. 想清楚目标；
2. 判断类型、套对应方法论；
3. 按五段式写提示词；
4. 拿到代码扫三眼（动原文件吗 / 有安全措施吗 / 是完整文件吗）；
5. 小范围先跑；
6. 出问题贴原文；
7. 跑通让 AI 大白话讲一遍；
8. **存下来**（代码和提示词都是资产，建个文件夹，三月后你就有专属提示词库）。

## 提示词模板盒子

### 模板一：万能五段式（通用头+主模板，存收藏夹）

```
【背景】我完全不会编程，Windows，已装 Python 3.11 和 VS Code，
       请当零基础每步说清。
【目标】一句话说清要做什么。
【输入输出】喂进什么（给格式样例）/ 要回什么（给格式样例）。
【约束】技术限制 + 边界处理 + 安全
       （不改原文件/先打印清单/带预演开关）。
【交付】完整可运行文件不要片段 / 加中文注释 /
       告诉我装什么怎么跑 / 多文件说清各自放哪。
```

### 模板二：改一处（改代码专用）

```
下面是我能正常运行的代码。
请只做这一处修改：【具体说明】。
要求：其他逻辑一律不要动；不要重构、不改变量名、不顺便优化；
     给改好完整文件。
【粘贴完整代码】
```

### 模板三：报错求助（万能）

```
【报错原文】从第一行到最后一行整段粘贴，未删改。
【环境】Windows/Python 3.11/其他信息
【期望结果】【实际发生】
请讲：1）根本原因（大白话）2）怎么改
     3）改好完整文件 4）以后怎么避免。
```

## 速查表

| 段 | 写什么 | 复用？ |
|---|---|---|
| 背景 | 水平+环境+姿态 | ✅ |
| 目标 | 一句话 | 每次新写 |
| 输入输出 | **给样例** | 每次新写 |
| 约束 | 技术+边界+安全 | ✅ |
| 交付 | 完整文件+注释+怎么跑 | ✅ |

铁律七字诀：要完整、改一处、贴原文、先跑通、先小后大、让它讲。

## 下篇预告

模块四"代码生成"八篇走完。**你不会写代码，但能让 AI 写出能跑的函数、能看的页面、能用的接口、合理的表、打通的小项目、替你干活的脚本——这挺不容易。** 但有个问题悬着：**AI 给你的东西你能跑，却看不懂。** 一旦不按预期工作，你连从哪查都不知道；更现实的是接手别人代码满屏符号。下一篇换个方向：不让 AI 帮你"写"，让它帮你"读"。第69篇：读不懂的代码丢给 AI 解释，讲怎么让它翻译成你妈都懂的话、三种深度讲解、画流程图、指出哪里有坑。看代码是你从"能用"迈向"用得放心"的分水岭。
