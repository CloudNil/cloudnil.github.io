> 周报好不容易 10 分钟内搞定了，领导一句"你出个XX方案"，你又盯着空白文档坐了两小时。

不是不会干活，是不知道从哪个字开始写。

**写方案难，难在三件事：**

- 脑子里有想法，落到纸上就散了
- 好不容易写完，领导说"没什么落地性"
- 格式跟公司现有方案对不上，被打回重排

上一篇讲了周报，那是小活儿。**这一篇上强度：一份能拿去评审的完整方案。**

还是之前反复提醒的事情：**AI 是个能力极强的新手，直接跟它说"帮我写个方案"，你永远只能得到一堆正确的废话。**

---

## 一、为什么"帮我写个方案"必然失败

试试看，你打开任何一个 AI，输入"帮我写一份市场推广方案"。

它会给你什么？大概是这样：

> 一、背景分析
> 随着市场竞争日益激烈，为进一步提升品牌影响力……
> 二、目标设定
> 提升品牌知名度，扩大市场份额……

**读起来很像那么回事，但你敢交上去吗？**

不敢。因为这里面**没有一个字是关于你的**——你的公司、你的预算、你的时间、你的老板到底想解决什么问题。

**AI 不是不会写，是你没给它写的材料。**

这就像你跟装修师傅说"帮我装个房子"，不说户型、不说预算、不说风格，他能给你的只有一张样板间效果图。

**所以正确的第一步，不是让 AI 写，是你要先把材料准备好，可以乱、可以杂，但不能没有，尽量齐全。**

## 二、五分钟准备：方案的"六个已知条件"

写方案前，先花五分钟，把下面六件事用大白话写下来。**不用写成句子，一行一个词都行。**

- **为什么要做** —— 领导为什么突然要这个方案？解决什么问题？
- **给谁看** —— 直属领导？评审会？客户？还是要报给总部？
- **做到什么程度** —— 想达成什么结果，有没有具体数字
- **手里有什么** —— 预算多少、几个人、多长时间
- **有什么限制** —— 不能碰的红线、必须配合的部门、硬性截止日期
- **参考什么** —— 公司以前有没有类似方案，格式是什么样的

**这六条，就是你的原料。**

举个真实点的例子：

```
为什么要做：新品下个月上市，老板要一份推广方案
给谁看：先给总监过，过了要上周会给几个部门讲
做到什么程度：上市首月拿到 500 个种子用户
手里有什么：预算 3 万，我 + 一个实习生，准备期 3 周
有什么限制：不能投硬广（品牌部不批），必须走内容渠道
参考什么：公司去年双十一的方案，是"背景-目标-策略-执行-预算-风险"六段式
```

**看到区别了吗？** 同样是"写个推广方案"，有了这六条，AI 才知道它在给谁、为什么、在什么条件下写什么。

> 虎哥的经验：**这五分钟是整个流程里性价比最高的五分钟。** 你少花这五分钟，后面就要多花两小时改稿。

## 三、核心方法：三轮成稿法

材料齐了，别急着一把梭。**方案不要一次让 AI 写完，要分三轮。**

为什么？因为一次生成的长文，你想改哪句都牵一发动全身。**分三轮，每轮只解决一件事，改起来才轻松。**

### 第一轮：只要大纲，不要正文

**这一轮的目的：把框架定死。**

```
你是一位有十年经验的方案策划专家，
擅长把模糊的需求整理成结构清晰、可落地的工作方案。

【方案主题】
[填，例如：新品上市推广方案]

【背景信息】
- 为什么要做：[填]
- 给谁看：[填]
- 目标：[填]
- 现有资源：[填]
- 限制条件：[填]

现在请先不要写正文。
只输出这份方案的详细大纲，要求：

1. 列出一级章节（5-7 个），每个章节标注它要回答什么问题；
2. 每个一级章节下列 2-4 个二级要点，用一句话说明该点要写什么；
3. 在大纲最后，列出「为了写好这份方案，你还需要我补充的信息」，
   最多 5 条，按重要性排序。

不要写具体内容，只要结构，你觉得不清楚或遗漏的地方，先跟我沟通确认，不要埋头执行。
```

**注意最后那条要求——让 AI 反过来问你。**

这一招特别好用。AI 会告诉你"你还没说竞品情况""你没说渠道有哪些"，**它问的每一个问题，都是你方案里迟早会被领导问到的漏洞。**

![three-rounds](/images/posts/2026-08-17-ai-29-three-rounds.png)

### 第二轮：逐章节填内容

大纲确认后，**一章一章地写，不要一次全写。**

```
上面的大纲我确认了，我们现在逐章节写。

请先写「第三部分：推广策略」这一章。

补充信息：
[把这一章需要的细节补上]

要求：
1. 字数 600-800 字；
2. 每个策略点必须包含：做什么 + 为什么这么做 + 大致怎么执行；
3. 涉及数字的地方，如果我没提供，向我提问，不要编；
4. 写完后，用一句话告诉我这一章还有什么薄弱环节。

这一章写完我确认后，我们再写下一章。
```

**为什么要一章一章写？**

- 每章都能单独看、单独改，不用推翻重来
- 很多 AI 在短篇幅上的质量明显高于长篇
- 你能随时补充新想法，不用等全文写完

**这就是"链式提问"的雏形**——把一个大任务拆成一串小任务，后面进阶篇会专门讲。

### 第三轮：让 AI 挑自己的毛病

全文出来了，**别急着交。让 AI 换个身份，来挑刺。**

```
现在请你切换角色：
你是这份方案的评审专家，立场偏严格，
你的任务是在评审会上找出这份方案的问题。

【方案全文】
[贴进来]

请从以下角度逐一挑毛病：

1. 逻辑漏洞：哪些结论缺少支撑，哪些前后矛盾；
2. 落地性：哪些动作看起来很美但实际做不了；
3. 资源匹配：目标和给出的人力、预算、时间是否对得上；
4. 遗漏项：一份合格的同类方案通常会有、但这份没有的内容；
5. 风险：执行过程中最可能出问题的三个点。

每条问题请说明：问题是什么 + 严重程度（高/中/低）+ 建议怎么改。
不要客气，也不要夸这份方案。
```

**最后那句"不要客气"很重要。** AI 天生有讨好倾向，你不明说，它会先夸你三段再提两个不痛不痒的小建议。

**这一轮通常能挖出 3-5 个真问题。** 提前自己发现，总比评审会上被人当众指出强。

> 小妙招：豆包生成的方案，你拿给DeepSeek或Kimi评审，直接告诉它们这是豆包写的。

## 四、杀手锏：让 AI 模仿公司现有格式

这一招能帮你省掉所有排版和风格的麻烦。

**做法很简单：把公司以前一份还不错的同类方案，直接贴给 AI。**

```
下面是我们公司之前一份已经通过评审的方案，
请你分析它的写作规范，然后按同样的规范来写我的新方案。

【参考方案】
[贴全文或贴前两千字]

请先告诉我你提取到的规范，包括：
1. 章节结构（有哪几部分，顺序如何）；
2. 每部分的详细程度和大致篇幅；
3. 语言风格（正式度、是否用第一人称、常用句式）；
4. 数据呈现方式（表格 / 列表 / 正文夹叙）；
5. 有没有固定的开头和结尾套路。

我确认后，你再按这个规范写我的新方案。
```

**为什么这招好用？**

因为公司的方案格式往往是"约定俗成"的——没人写在纸上，但你格式不对就是显得外行。**AI 一眼就能把这些隐性规则提取出来。**

**没有参考方案怎么办？** 找行业里公开的优秀案例，或者直接问 AI："我们这个行业的 XX 方案，通常包含哪些部分？"

## 五、四个常见坑，提前避开

**坑一：让 AI 编数据。**
方案里的市场规模、增长率、竞品数据，**AI 会编得有鼻子有眼，而且编得很像真的。** 一定要求它"没有的数据让你补充"，然后自己去查。评审会上被问到数据出处而你答不上来，是最难堪的场面。

**坑二：一次生成一万字。**
篇幅越长，AI 越容易前后矛盾、重复啰嗦。**分章节，永远分章节。**

**坑三：直接照抄不读一遍。**
AI 写的东西通顺归通顺，但可能出现你们公司根本不用的说法、不存在的部门名称。**交之前至少通读一遍。**

**坑四：不做减法。**
AI 倾向于写得多、写得全。但**方案不是越长越好**，领导看的是重点。写完后加一句："请把这份方案压缩到原来的 70%，删掉重复和不必要的修饰，保留所有实质内容。"

> 虎哥的大实话：**AI 写方案的价值，不是替你思考，是帮你把想法快速变成规范的文字。** 方案好不好，本质还是看你对业务的理解。**但一份想法七分、表达三分的方案，和一份想法七分、表达九分的方案，在别人眼里完全是两个东西。**

## 📦 提示词模板盒子

### 模板一：第一轮 · 只要大纲（起手式）

```
你是一位有十年经验的方案策划专家，
擅长把模糊的需求整理成结构清晰、可落地的工作方案。

【方案主题】
[填，例如：新品上市推广方案]

【背景信息】

- 目标：[想达成什么结果，有数字填数字]

现在请先不要写正文，只输出详细大纲：

1. 列出一级章节（5-7 个），每个标注它要回答什么问题；
2. 每个一级章节下列 2-4 个二级要点，
   用一句话说明该点要写什么；
3. 最后列出「为了写好这份方案，你还需要我补充的信息」，
   最多 5 条，按重要性排序。

不要写具体内容，只要结构，你觉得不清楚或遗漏的地方，先跟我沟通确认，不要埋头执行。
```

### 模板二：第二轮 · 逐章节生成

```
上面的大纲我确认了，我们逐章节写，不要一次全写完。

请先写「[章节名]」这一章。

【本章补充信息】
- [填这一章需要的细节]
- [继续]

要求：
1. 字数 [600-800] 字；
2. 每个要点必须包含：做什么 + 为什么这么做 + 大致怎么执行；
3. 我没提供的数字一律标注[待填]，严禁编造；
4. 不要写"积极推进""高度重视""持续优化"这类空话；
5. 写完后用一句话告诉我：这一章还有什么薄弱环节。

这一章我确认后，我们再写下一章。
```

### 模板三：第三轮 · 让 AI 当评审专家挑刺

```
现在请切换角色：
你是这份方案的评审专家，立场偏严格，
任务是在评审会上找出这份方案的问题。

【方案全文】
[贴进来]

请从以下角度逐一挑毛病：

1. 逻辑漏洞：哪些结论缺少支撑，哪些前后矛盾；
2. 落地性：哪些动作看起来很美但实际做不了；
3. 资源匹配：目标和给出的人力、预算、时间是否对得上；
4. 遗漏项：同类方案通常会有、但这份没有的内容；
5. 风险：执行过程中最可能出问题的三个点。

每条请说明：
问题是什么 + 严重程度（高/中/低）+ 建议怎么改。

不要客气，也不要夸这份方案。
最后按"必须改 / 建议改 / 可以不改"给我一个修改优先级清单。
```

### 模板四：模仿公司现有方案格式

```
下面是我们公司之前一份已经通过评审的方案，
请分析它的写作规范，然后按同样规范写我的新方案。

【参考方案】
[贴全文或前两千字]

请先告诉我你提取到的规范：
1. 章节结构（有哪几部分，顺序如何）；
2. 每部分的详细程度和大致篇幅；
3. 语言风格（正式度、人称、常用句式）；
4. 数据呈现方式（表格 / 列表 / 正文夹叙）；
5. 固定的开头和结尾套路。

我确认规范后，你再按这个规范写我的新方案，
新方案主题是：[填]
```

### 模板五：成稿瘦身（交稿前最后一步）

```
下面这份方案有点长，领导没耐心看完。
请帮我压缩到原来的 [70%]。

【方案全文】
[贴进来]

压缩原则：
1. 保留所有实质内容：目标、数字、具体动作、时间节点、责任人；
2. 删掉重复表达、过渡性废话、修饰性形容词；
3. 能用列表说清的，不要用大段文字；
4. 不许删掉任何一条风险和限制条件。

输出两部分：
一、压缩后的全文；
二、我删掉了哪些内容（列个清单，方便你确认有没有误删）。
```

## 下篇预告

方案是大活儿，下一篇回到日常。

**下一篇《让 AI 润色和改写文案（去口语/升正式）》**——把你随手打的大白话，变成能发出去的专业表达。

虎哥会讲清楚：

- **为什么说"帮我润色一下"永远得到浮夸文风**，正确的说法是什么
- **一句话七种语气**：同一个意思，对老板、对客户、对同事该怎么说
- 怎么让 AI **只改表达不改意思**（这是润色最容易翻车的地方）
- 一个反向技巧：**把 AI 味十足的官腔，改回人话**

**写得出来是一回事，写得得体是另一回事。** 下一篇教你后者。
