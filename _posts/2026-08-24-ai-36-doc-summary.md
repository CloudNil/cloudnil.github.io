## 一、先回头看：这九篇其实只讲了一件事

九个场景，看起来五花八门。但你把它们摆在一起会发现——**底层是同一套动作。**

**所有文档类任务，都可以拆成四个动作：**

- **定身份**：让 AI 站在谁的位置上说话
- **给素材**：把它不知道的信息喂进去
- **提要求**：格式、长度、语气、禁忌
- **要修改**：第一版从来不是最终版

**第 27 篇讲的「角色 + 任务 + 格式 + 约束」，就是前三个动作的展开。**

而九篇里所有的场景差异，**只是这四个动作里填的内容不同而已。**

举个对照：

| 场景 | 定身份 | 给素材 | 提要求 |
|---|---|---|---|
| 周报 | 你是我的下属，帮我整理汇报 | 这周做了哪几件事 | 三段式、突出结果、不超300字 |
| 邮件 | 你是职场沟通顾问 | 收件人身份、我要达成什么 | 礼貌但不卑微、正文5行内 |
| 公文 | 你是机关文秘 | 发文单位、事由、要求 | 符合公文格式、用规范文种 |
| 翻译 | 你是母语编辑 | 术语表、使用场景 | 不逐词直译、给两版 |

**看出来了吗？换汤不换药。**

**你真正要记住的不是九个模板，是这四个动作。** 记住了，遇到没讲过的场景你也能自己组。

## 三、一个万能骨架，套什么场景都行

如果你只想记一个模板，**就记这个。**

它是从九篇里提炼出来的最小公共结构，**填空就能用**：

```
【角色】你是一位……（有X年经验的……）
【任务】请帮我……（一句话说清要产出什么）
【背景】……（AI不知道、但影响结果的信息）
【读者】这份东西给……看，他最关心……
【格式】请按……结构输出，篇幅约……字
【禁忌】不要……（明确列出你不想看到的东西）
```

**六行，每行填一句。**

**为什么这个骨架有效？** 因为它堵住了新手最容易漏的三个信息缺口：

- **漏了「读者」** → AI 只能按最通用的方式写，出来的东西谁看都不合适
- **漏了「背景」** → AI 只能编，于是出现「幻觉」
- **漏了「禁忌」** → AI 会自作主张加一堆你不想要的套话

**特别强调「禁忌」这一行。** 新手很少写，但它的效果往往最立竿见影。

比如加上「不要用『赋能』『抓手』『闭环』这类词」，**你的稿子瞬间就没有官腔，充满人味了。**

## 四、新手最常犯的 7 个错

这九篇写下来，虎哥收到的提问高度集中。**这七个错，几乎人人都犯过。**

### 错误 1：把 AI 当搜索引擎，只给一句话

「帮我写个周报。」——**这不是需求，这是许愿。**

**AI 不知道你这周干了什么。** 它只能给你一份放之四海而皆准的废话。

**正确做法：先把流水账倒给它，哪怕写得乱七八糟。**

### 错误 2：只要一版，拿到就用

**第一版永远是最保守、最平庸的版本。**

AI 在不确定你要什么的时候，会给一个「不会出错」的答案。**不会出错 = 也不出彩。**

**正确做法：拿到第一版之后，至少提一轮修改意见。**

### 错误 3：修改意见说得太虚

「感觉不太好，你再改改。」——**说了等于没说，AI 完全不知道你指的是哪里。**

**正确做法：指出具体位置 + 具体问题 + 期望方向。**

比如：「第二段太空了，加两个具体数字」比「第二段不好」有用一百倍。

### 错误 4：不检查事实，直接采信

**AI 会编数字、编日期、编政策条款，而且编得非常像真的。**

**正确做法：凡是数字、时间、人名、政策依据，一律自己核对一遍。**

**尤其是要发出去给别人看的文档。**

### 错误 5：一个对话里啥都聊

写着周报，突然又问翻译，聊完又回来改周报。

**上下文一乱，AI 的输出质量断崖式下跌。**

**正确做法：一个任务开一个新对话。** 这是成本最低的提效手段。

### 错误 6：把敏感信息直接贴进去

客户名单、身份证号、内部财务数据、未公开的合同条款……

**第 20 篇专门讲过这个，这里再强调一次。**

**正确做法：脱敏后再贴。** 人名换成「A 先生」，公司换成「甲方」，数字改成量级相近的假数。

### 错误 7：模板收藏了，但从来不改

**别人的模板是别人的场景。**

直接抄，效果一定打折。

**正确做法：用过两三次之后，把不合适的地方改掉，存成你自己的版本。**

**你自己的模板库，才是这九篇真正的产出物。**

## 五、30 天文档提效自检清单

**学完不等于会用。会用不等于成习惯。**

下面这份清单，虎哥建议你按周推进，**一个月之后回头看，变化会很明显。**

**第 1 周：先把最高频的一件事跑通**

- [ ] 选定你每周必做的一件文档任务（多数人是周报）
- [ ] 用第 28 篇的模板完整跑一次
- [ ] 记录：省了多少时间？哪里还得手动改？
- [ ] 把改动写回模板，存成你自己的版本

**第 2 周：扩展到三个场景**

- [ ] 再挑两个高频场景（邮件 / 会议纪要 / 方案，任选）
- [ ] 每个场景都跑通一次并存下自己的模板
- [ ] 建一个笔记文件夹，专门放这些模板

**第 3 周：练「改」的能力**

- [ ] 这周不追求一次到位，专门练提修改意见
- [ ] 每次至少提三轮：结构 → 内容 → 措辞
- [ ] 观察：哪种说法能让 AI 改得最准

**第 4 周：形成检查习惯**

- [ ] 每份发出去的文档，过一遍事实核对
- [ ] 每份涉及外部的文档，过一遍脱敏检查
- [ ] 整理你的模板库，删掉没用过的，合并重复的

**一个月后你应该拥有：3-5 个自己的模板、一套核对习惯、以及「不用从零开始写」的底气。**

## 六、下一个模块，难度会往上走一点

文档类讲完了。**接下来是 PPT 类。**

为什么把 PPT 放在文档后面？因为**PPT 的本质是「结构化的文档 + 视觉表达」**。

- 前半部分（大纲、讲稿、内容）——**用的还是你刚学会的这套东西**
- 后半部分（排版、配图、美化）——**是新内容**

所以文档类学得扎实，**PPT 类会轻松很多。**

**如果你前面九篇是跳着看的，建议至少把第 27 篇（提示词四要素）和第 29 篇（三轮成稿法）补上。** 这两篇是后面所有内容的地基。

## 提示词模板盒子

**模板一：万能六行骨架（记住这一个就够）**

```
【角色】你是一位……（写清专业身份和经验年限）
【任务】请帮我……（一句话说清要产出什么东西）
【背景】……（AI不知道、但会影响结果的所有信息：
        项目情况、时间节点、已有进展、相关人员）
【读者】这份东西是给……看的，他最关心的是……，
        他的顾虑可能是……
【格式】请按……结构输出（如：总-分-总/三段式/表格），
        篇幅约……字
【禁忌】不要出现……（如：空话套话、赋能抓手闭环这类词、
        没有依据的数字、过度承诺的表述）

如果上面的信息里有你完成任务所必需但我没提供的，
请先向我提问，不要自行假设。
```

**模板二：三轮修改指令（改稿专用）**

```
【第一轮 · 改结构】
先不要动措辞。请只从结构上评估这份稿子：
1. 段落顺序是否合理，有没有该提前或后置的内容；
2. 有没有该有但缺失的部分；
3. 有没有重复或可以合并的部分。
请给出调整建议，并输出调整后的提纲（先别写正文）。

【第二轮 · 改内容】
结构确认了。现在请检查内容：
1. 哪些地方是空话，需要补充具体事实、数字或案例；
2. 哪些论述缺乏依据，站不住脚；
3. 哪些地方对读者来说信息不足，需要补充说明。
请直接给出修改后的版本，并用【修改说明】标注你改了什么。

【第三轮 · 改措辞】
内容定了。现在只做语言层面的优化：
1. 删掉所有冗余修饰和套话；
2. 长句拆短；
3. 统一语气（目标语气：……）；
4. 不要使用 [列出你讨厌的词]。
请输出最终稿。
```

**模板三：发布前自检（防翻车）**

```
下面这份文档我准备发出去了。发出前请帮我做一次全面检查。

[贴入文档]

请逐项检查并列出问题：

一、事实核查
   文中所有数字、日期、人名、机构名、政策依据，
   请逐一列出，并标注：可核实 / 需我确认 / 疑似AI生成。

二、逻辑检查
   有没有前后矛盾、因果不成立、结论超出论据支撑的地方。

三、表述风险
   有没有过度承诺、绝对化表述、可能引起歧义或误解的句子。

四、格式规范
   称谓、落款、日期格式、标题层级是否规范统一。

五、敏感信息
   有没有不适合出现在这份文档里的内部信息、
   个人隐私、未公开数据。

请按"位置 - 问题 - 建议"三列输出。
没问题的项目也请明确说"未发现问题"。
```
