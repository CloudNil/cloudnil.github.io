> 网页做出来了，一刷新，填的东西全没了。

上一篇你做出了能双击打开的网页。挺爽的。**但它有个致命毛病：一刷新，全白。**

你在待办清单加了五条，关掉浏览器再打开——一条不剩。你做的名片页发给朋友，他改了名字你这边看不到。

**因为你的网页，是个失忆症患者。** 它没有"记事本"也没有"传话人"。今天给它配上这两样，叫**后端接口**。

**先吃颗定心丸**：这篇你依然一行代码都不用手写。不装数据库、不租服务器、不配环境——**在自己电脑上，二十分钟跑起来一个真接口**。

---

## 一、后端到底是个什么东西

**你打开美团点了一份麻辣烫。**

- 你看到的菜单、点"提交订单"——这是**前端**（第62篇做的）
- 订单跑去哪儿了？谁记下你要麻辣烫？谁通知商家？——这是**后端**

**再换个更土的比方：餐厅。**

| 角色 | 技术名 | 干什么 |
|---|---|---|
| 前厅的菜单和服务员 | 前端 | 给客人看、让客人点 |
| 服务员传菜单进后厨 | 接口（API） | 传话的窗口 |
| 后厨 | 后端 | 真正干活的地方 |
| 冰箱和库存本 | 数据库 | 关门也不会消失 |

**"接口"的真身就是"传菜口"。** 所有交流都从那个窗口过。**所以后端接口是什么？就是一个约定好的窗口地址，你往那儿喊一嗓子，它回你一句。**

## 二、五个单词，看懂所有接口

接口世界里**只有四个动作**。微信、淘宝、你公司 OA，后端干的活都逃不出这四样：

| 动作 | 英文 | 大白话 | 生活例子 |
|---|---|---|---|
| 查 | GET | 给我看看 | 打开待办列表 |
| 增 | POST | 记一条新的 | 添加一条待办 |
| 改 | PUT | 把这条改了 | 把"买菜"改成"买肉" |
| 删 | DELETE | 把这条扔了 | 删掉已完成的事 |

**这四个字连起来叫"增删改查"**，英文圈叫 **CRUD**。

> **记住这条你赢了一半**：所有后端开发，本质都是给不同东西写"增删改查"。给用户写一套、给订单写一套。**招式就那四招，只是换对象。**

**还有一个天天见的词：接口地址（URL）。** 它长这样：

```
GET    /api/todos        → 查所有待办
POST   /api/todos        → 新增一条待办
PUT    /api/todos/3      → 修改编号 3 的待办
DELETE /api/todos/3      → 删除编号 3 的待办
```

**地址一样，动作不同，事就不同。** 像同一个传菜口，喊"上菜"和"退菜"，后厨反应完全不同。

## 三、动手前：装一样东西，就一样

前端双击就能跑。后端不行，**它需要一个一直运行的程序在那儿待命**。推荐 **Node.js**：安装最傻瓜、和上篇网页同一种语言（JavaScript）、AI 支持最好。

**安装三步：**
1）搜 Node.js 官网，点绿色 **LTS 版**；
2）下载后双击，一路"下一步"；
3）装完开命令行（Win+R 输 `cmd`），输入 `node -v`。

**冒出一串数字（如 `v20.11.0`）就装好了**；提示"不是内部或外部命令"就重启电脑再试。

![nodejs-setup](/images/posts/2026-09-20-ai-63-nodejs-setup.png)

## 四、核心：怎么跟 AI 描述一个接口

第61篇讲函数"四要素"，第62篇讲页面"五要素"。**描述接口，是"四件套"。**

1. **这是给什么用的（业务对象）**：一句话说清管什么东西。"我要做一个**待办清单**的后端。" 别说"做个后端"，AI 不知道你管待办还是订单。
2. **每条数据长什么样（字段）**：**最易漏、也最重要。** 一条待办含：编号（自动生成）、内容（文字）、是否完成（是/否，默认否）、创建时间（自动记）。
3. **需要哪几个接口（动作清单）**：对照 CRUD 直接列——查全部、增一条、改一条、删一条。
4. **技术约束（别让 AI 自由发挥）**：**这条保命。** 不写它，AI 可能给你一套要装 MySQL、配 Redis、跑 Docker 的"企业级方案"，光配环境就两天。

**"数据先存内存里"是新手救命符**——不用装库、不用建表。缺点是重启丢数据，但你是学原理不是上线，够用。

## 五、实战：二十分钟跑通第一个接口

打开 Cursor（或任意 AI 对话框），把下面这段**整段复制**进去（完整模板见文末）：

```
我完全不懂后端开发，请手把手教我。
【要做什么】一个待办清单的后端接口。
【每条数据的字段】
- id：编号，自动生成，从1递增
- content：待办内容，文字
- done：是否完成，true/false，默认 false
- createdAt：创建时间，自动记录
【需要哪些接口】
1. GET  /api/todos      查询全部
2. POST /api/todos      新增一条（只需传 content）
3. PUT  /api/todos/:id  修改某条（可改 content 或 done）
4. DELETE /api/todos/:id 删除某条
【技术要求】
- Node.js + Express
- 数据存在内存数组里，不要连数据库
- 全部代码放在一个文件 server.js
- 端口 3000，允许跨域
- 每一行关键代码加中文注释
【我要的输出】
1. 完整的 server.js，不要片段
2. 我需要按顺序执行的命令行命令
3. 跑起来后怎么验证四个接口
```

**AI 会给你三样东西：**

1. **安装命令**：`mkdir my-api` → `cd my-api` → `npm init -y` → `npm install express cors`。看到一堆滚动文字别慌，那是下载，停了就好。
2. **代码**：把 `server.js` 完整复制，在 my-api 文件夹新建 `server.js` 粘进去。**要完整文件，不要拼凑。**
3. **启动命令**：`node server.js`。回车后看到 `服务已启动，访问 http://localhost:3000`，**恭喜，你运行起了人生第一个服务器。**

> **重要：这个黑窗口不能关。** 它关了服务就停，理解为"后厨的灯"，灯灭了没人做菜。要写别的命令，**另开一个命令行窗口**。

## 六、怎么验证接口是好的：三招

1. **浏览器直接开（只能测"查"）**：地址栏输 `http://localhost:3000/api/todos`。**看到 `[]`（空方括号）就是成功**——空列表说明接口通了，你还没加数据。
2. **让 AI 给你写测试网页（推荐）**："基于刚才的接口，帮我做 test.html：有输入框和添加按钮，下方显示所有待办，每条后有标记完成和删除按钮，用 fetch 调四个接口，单文件双击打开。" 双击打开就能点点点测所有接口，**还顺便把第62篇前端和这篇后端接上了——这就是"全栈"**。
3. **命令行发请求（进阶，可跳过）**：出现 `curl` 开头的命令，看不懂就跳过，招式二完全够。

![three-verify](/images/posts/2026-09-20-ai-63-three-verify.png)

## 七、四个必踩的坑，提前告诉你

- **坑1：端口被占用**——报错 `EADDRINUSE`。人话"3000 门牌号有人住了"。解法：让 AI 改端口 3001，或关掉旧窗口。
- **坑2：网页调不通，报 CORS 错误**——后端不认识来访网页，拦在门外。这就是提示词里写"允许跨域"的原因；还报就让 AI 加 cors 中间件。
- **坑3：改完代码没生效**——后端不像网页改完刷新就行，**必须重启**：`Ctrl+C` 停掉，再 `node server.js`。
- **坑4：重启后数据全没了**——**这不是 bug，是设计。** 因为数据"存在内存里"。要真正记住得用数据库，那是下一篇。

![four-pitfalls](/images/posts/2026-09-20-ai-63-four-pitfalls.png)

## 八、三条铁律，抄下来贴显示器上

- **铁律一：先跑通一个接口，再要四个。** 别一上来让 AI 把 CRUD 全写。先只要 `GET`，跑通再要下一个。**一次加一个，出错知道是谁的锅。**
- **铁律二：报错就把原文全部贴给 AI，别转述。** 新手爱说"它报错了"，AI 只能猜。**把红色那几行完整复制粘贴**，命中率从 30% 提到 90%。
- **铁律三：永远要"完整文件"。** 这条从第61篇讲到现在。AI 说"把这行改成……"你容易插错位置。**直接说"给我完整的 server.js"**，整个覆盖，零出错。

## 速查：后端四件套

| 序号 | 要素 | 一句话 | 漏了会怎样 |
|---|---|---|---|
| 1 | 业务对象 | 我要管什么东西 | AI 不知道给谁做 |
| 2 | 字段清单 | 每条数据长什么样 | AI 瞎猜，全返工 |
| 3 | 动作清单 | 需要哪几个接口 | 给你多了或少了 |
| 4 | 技术约束 | 用什么、别用什么 | 给你企业级方案，配两天环境 |

## 速查：报错对照

| 报错关键词 | 人话 | 解法 |
|---|---|---|
| `EADDRINUSE` | 端口被占了 | 换端口或关旧窗口 |
| `CORS` | 网页被拦门外 | 加 cors 中间件 |
| `Cannot find module` | 工具包没装 | `npm install 包名` |
| 改完没反应 | 服务没重启 | Ctrl+C 后重新启动 |
