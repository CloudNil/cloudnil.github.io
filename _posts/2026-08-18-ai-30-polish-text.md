> 消息编辑框里删删改改十分钟，最后发出去一句"好的收到"。

不是不会说，是怕说得不得体。

**同一个意思，说法不一样，结果差很远：**

- "这事我做不了" vs "这部分需要 XX 支持，我这边可以先推进 YY"
- "方案有问题" vs "方案里有两点想再确认一下"
- "催一下进度" vs "想同步下当前进展，看看有没有需要我配合的"

内容没变，**但别人对你的印象完全不一样。**

上一篇讲了方案这种大活儿。这一篇回到日常里最高频的动作：**把已经写出来的东西，改得更好。**

---

## 一、为什么"帮我润色一下"总是翻车

你肯定试过。把一段话丢给 AI，说"帮我润色一下"。

它还给你的东西通常长这样：

> 在当前快速发展的业务环境下，我们高度重视本项目的推进工作，
> 并将持续优化相关流程，以确保各项目标的顺利达成。

**你原本想说的是："这个项目我们在做，下周能出结果。"**

十四个字，被它撑成了五十个字的官腔。

**问题出在哪？**

"润色"这个词太模糊了。**在 AI 的理解里，"润色"约等于"加形容词、换书面语、拉长句子"。** 它不知道你要发给谁、要什么语气、能不能改意思。

**所以第一条铁律：永远不要只说"润色一下"。**

要说清三件事：

- **改成什么风格**（正式 / 口语 / 简洁 / 亲和）
- **给谁看**（老板 / 客户 / 同事 / 公众）
- **能不能改意思**（大多数情况下：不能）

## 二、润色的正确说法：三段式

虎哥用得最顺手的一套，就三段。

```
请把下面这段话改写成 [正式书面语]，
用于 [发给客户的项目进度邮件]。

【原文】
[贴进来]

要求：
1. 不得改变原意，不得增加我没说的信息；
2. 字数控制在原文的 0.8~1.2 倍以内；
3. 去掉口语词和语气词；
4. 说人话，别打官腔。
```

**拆开看，每一条都在堵一个坑：**

- **不得改变原意** —— 堵住 AI 自作主张加内容
- **字数上下限** —— 堵住走极端的篇幅调整
- **去掉口语词** —— 明确"正式"的具体含义
- **说人话** —— 堵住官腔

**最后那条"说人话"，是虎哥吃过亏才加上的。** 不加这句，AI 十次有八次给你写成机关公文。

## 三、一句话七种语气

这是本篇最实用的部分。

**同一句话，换个场合就要换个说法。** 与其每次现想，不如让 AI 一次给你七个版本，你挑一个。

```
下面这句话，请帮我生成 7 个不同语气的版本，
方便我根据场合挑选。

【原句】
[贴进来]

请分别输出：

1. 正式书面 —— 用于邮件、公文、对外沟通
2. 专业简洁 —— 用于工作群、日常汇报
3. 委婉客气 —— 用于向上沟通、有求于人时
4. 坚定明确 —— 用于表达立场、拒绝不合理要求
5. 轻松口语 —— 用于熟悉的同事之间
6. 极简版 —— 一句话说完，不超过 20 字
7. 亲和温暖 —— 用于安抚情绪、处理投诉

统一要求：
- 七个版本的核心意思必须完全一致；
- 不许添加原句里没有的承诺、时间、数字；
- 每个版本后面用一句话说明"适合什么场合"。
```

**举个例子。原句："这个我下周才能给你。"**

AI 会给你：

- **正式书面**："该部分内容预计于下周提交，届时将第一时间同步。"
- **专业简洁**："这块下周出，出来我发你。"
- **委婉客气**："这部分我尽量下周给到您，如果时间上有压力，也可以先看下现有的部分。"
- **坚定明确**："下周给。这周的排期已经满了，提前不了。"
- **轻松口语**："下周给你哈，这周实在排不开。"
- **极简版**："下周给你。"
- **亲和温暖**："知道你着急，我这边下周一定给到，中间有进展我随时跟你说。"

**看到没有？同样一件事，七种态度。**

第四个版本能帮你守住边界，第七个版本能帮你留住关系。**你缺的从来不是内容，是词。**

## 四、最容易翻车的地方：改表达，还是改意思

这是润色里最危险的一件事。

**AI 在改写时，很容易顺手"帮你"补一点、圆一点、说得满一点。**

真实的例子：

- 你写"这周应该能做完" → AI 改成"本周内将完成"（**"应该"变成了承诺**）
- 你写"我们考虑了这个方案" → AI 改成"我们已充分论证该方案"（**"考虑"变成了"论证"**）
- 你写"效果还行" → AI 改成"效果显著提升"（**没数据的夸大**）

**这些改动看着无害，但白纸黑字发出去，是要负责的。**

**防翻车的约束，抄这三条：**

```
改写红线（必须严格遵守）：
1. 不得改变任何表述的确定性等级：
   "可能/应该/大概"不许改成"一定/将会/必然"；
   "考虑/初步/尝试"不许改成"完成/确定/论证"；
2. 不得添加任何我没写的数字、时间、人名、承诺；
3. 不得把程度词升级（"还行"不许改成"优秀"）；
4. 改完后，单独列出你调整过的关键表述，
   格式：原文 → 改后，方便我逐条核对。
```

**最后那条"列出改动"是保命的。** 你不用逐字对比，扫一眼改动清单就知道有没有被"美化"过头。

> 虎哥的血泪教训：**发出去的字，就是你的承诺。** AI 帮你说得更好听，但责任还是你的。**润色可以，注水不行。**

## 五、反向技巧：把 AI 味改回人话

这一招现在越来越有用。本文先讲用提示词方式如何去AI味，后边讲Agent工具的时候，再讲去AI味的Skill，那个更加方便使用。

**你有没有发现，很多人发的文章一眼就能看出是 AI 写的。** 特征很明显：

- 爱用"在……的背景下""值得注意的是""综上所述"
- 排比句一串一串，每段都是三点
- 形容词堆叠："高效、精准、全面地……"
- 空话密度高，两三句话的事讲一大段，净是废话套话

**如果你需要的是"像人写的"，就反过来要求：**

```
下面这段话有明显的 AI 写作痕迹，
请帮我改成像真人随手写出来的样子。

【原文】
[贴进来]

具体要求：
1. 删掉所有套话开头，
   如"在……的背景下""随着……的发展""值得注意的是"；
2. 长短句交替，不要每句都一样长；
3. 减少形容词，能用动词说清就用动词；
4. 允许出现口语化的短句和不完整句；
5. 不要每段都凑成三点，该两点就两点；
6. 保留原意和所有事实信息。

改完后告诉我：原文里哪些地方最像 AI 写的。
```

**什么时候用这招？**

- 写公众号、朋友圈、小红书这类要"人味"的内容
- 给熟悉的人发消息，不想显得生分
- 学生作业、个人陈述这类需要个人风格的场合

**反过来，什么时候需要"AI 味"？** 正式公文、合规文件、对外声明——**这些场合的"没人味"反而是优点。**

## 六、四个日常高频场景，直接套

**场景一：把语音转文字整理成通顺文字。**

```
下面是一段语音转文字的记录，有口语重复和错别字。
请整理成通顺的书面文字。
只做整理，不做扩写，不加任何我没说的内容。
听不清或明显是识别错误的地方，用[?]标出来，不要猜。

[贴进来]
```

**场景二：把长句拆短，让人读得下去。**

```
下面这段话句子太长，读起来累。
请在不改变意思的前提下拆成短句。
要求：单句不超过 25 字，可以适当分段，
不许删掉任何信息点。

[贴进来]
```

**场景三：统一多人写的文档风格。**

```
下面这份文档是几个人分别写的，风格不统一。
请统一成 [正式、简洁、第三人称] 的风格。
要求：
1. 只改表达，不改内容和结论；
2. 统一术语（同一个东西前后要用同一个说法）；
3. 统一格式（标题层级、列表符号、数字写法）；
4. 最后列出你统一了哪些术语。

[贴进来]
```

**场景四：把中式表达改自然（写英文时特别有用）。**

```
下面这段中文，请翻译成英文，
要求是母语者会自然说出来的表达，
不要逐字直译。
翻译后，把其中你做了"意译"的地方列出来，
说明原文是什么、为什么这么处理。

[贴进来]
```

**这四个模板存起来，覆盖你日常八成的改写需求。**

> 虎哥的大实话：**润色不是把话说漂亮，是把话说准。** 准确、得体、不多不少——这是职场文字的最高标准。**漂亮是附赠的。**

## 📦 提示词模板盒子

### 模板一：万能润色三段式（最常用）

```
请把下面这段话改写成 [正式书面语 / 简洁口语 / 亲和友好]，
用于 [发给客户的邮件 / 工作群消息 / 对外公告]。

【原文】
[贴进来]

要求：
1. 不得改变原意，不得增加我没说的信息；
2. 字数控制在原文的 [1.2] 倍以内；
3. 去掉口语词、语气词和重复表达；
4. 保持人话，不要写成公文腔；
5. 改完后告诉我：你主要调整了哪几处。
```

### 模板三：防注水改写（保命用）

```
请改写下面这段文字，
但必须严格遵守以下红线：

【原文】
[贴进来]

改写红线：
1. 不得改变任何表述的确定性等级：
   "可能/应该/大概"不许改成"一定/将会/必然"；
   "考虑/初步/尝试"不许改成"完成/确定/论证"；

4. 不确定的地方保留原样，并标注[请自行确认]。

输出两部分：
一、改写后的全文；
二、改动清单，格式为「原文 → 改后」，逐条列出。
```
