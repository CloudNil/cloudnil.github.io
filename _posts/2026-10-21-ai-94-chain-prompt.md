> "帮我做一份年度总结PPT"——AI给了，但没一页能用。

你敲下一句"帮我写一份完整的年度工作总结，要有数据、有亮点、有反思、有明年规划"，回车。AI 唰唰吐一大篇，全是"持续推进""稳步提升"的正确废话，**哪句都对，哪句都用不上**。

**这不是 AI 不行，是你的任务太大了。**

上一篇解决"一次提问怎么问准"。这一篇解决另一个问题：

> **当一件事大到一次提问装不下，怎么办？**

四个字：**拆开来问**——把一个大活儿切成一串小活儿，上一环的结果当下一环的原料。

![拆开才咽得下](/images/posts/2026-10-21-ai-94-拆开才咽得下.png)

## 一、一次问太大，必现三症状

**空。** 全是"加强协同""提升效率"的正确废话，**读完不知道明天干啥**。任务范围太大，AI 没法深入任一点。

**漏。** 你要么四块，结果前两块洋洋洒洒，**反思带过、规划没了**——一次要求太多，AI 优先满足前几件（第84篇铁律：**一次只干一件事**）。

**断。** 写着写着来一句"其余部分同理，此处省略"——单次输出有上限，超出它一口气能吐完的量。

> **看到空、漏、断，不要重问，要拆开。**

很多人会骂一句再问一遍，或加"写详细点"，结果还是空、漏、断——**病根没除**。

![三症状](/images/posts/2026-10-21-ai-94-三症状.png)

## 二、拆任务四刀

**按阶段切（先想后做）——最常用也最易被跳过。** 别一上来就让 AI 写，**先要大纲你确认再写**。

> 第1问：先给大纲，只要目录不要正文
> 第2问：（确认后）按目录写第一部分

**最重要的一刀**：方向错了写得再细也白费，**先确认目录省 30 分钟返工**。

**按模块切（一次一块）。** 20 页 PPT 别说"写 20 页"，说"先写第二章三页"。标准：一次要的量，你能一眼看完当场判断好坏。

**按角色切。** 先当**策划**（突出什么、受众关心什么）→ 再当**写手** → 最后当**审稿**（挑刺的领导视角）。**写手不挑自己毛病，换审稿身份毫不留情。**

**按粒度切。** 框架 → 填充 → 润色。

| 刀法 | 什么时候用 | 关键句 |
|---|---|---|
| 按阶段 | 几乎所有大任务 | "先只给大纲，不写正文" |
| 按模块 | 内容分块明确 | "这次只写第二部分" |
| 按角色 | 需质量把关 | "换身份，站领导角度挑刺" |
| 按粒度 | 要成品质量 | "先给骨架，内容下一步填" |

![拆任务四刀](/images/posts/2026-10-21-ai-94-拆任务四刀.png)

## 三、链式四步：框→填→接→合

**第一步：框——先要框架，人来确认。**

> "先只输出目录，不要写任何正文。等我确认后再继续。"

**"等我确认后再继续"是整条链的开关**——不加这句 AI 会一路狂奔把正文写完。拿到目录你要**改**：删多余的、补它没想到的、调顺序，**这步每分钟都十倍还给你**。

**第二步：填——一次一块。**

> "按确认的目录，现在只写第二部分。其余先不写。"

每写完一块**当场看一眼**，不能用就在这块改，别往下走。**新手常犯的错：一口气要五块，第一块调子错了五块全废。**

**第三步：接——把上一环结果贴回。**

> 聊得越久，AI 越容易忘前面说过的话。

**解法：每环开头重贴"项目卡片"**（见模板2）。**六行字，防住九成跑偏。**

**第四步：合——合并统稿。**

> "下面是分五次写完的全部内容。不要改任何事实和数据，只做三件事：①统一语气；②删重复；③查矛盾，有就单独列出来。"

**务必加"不要改事实和数据"这句**——不加，AI 统稿时爱把数字"优化"掉。

![链式四步](/images/posts/2026-10-21-ai-94-链式四步.png)

## 四、让 AI"停下来等你"的三句开关

| 场景 | 开关句 |
|---|---|
| 不让写正文 | "先只输出【目录/方案】，不写正文，等我确认再继续。" |
| 不让一次写完 | "这次只处理第 N 部分，其余我另说。" |
| 先问再做 | "动手前先问我 3 个你不知道但关键的问题，答完再动。" |

**第三句是隐藏神器**：不知道该补什么，就**让它自己问**，它问的往往是你没想到却关键的点。

---

## 五、断链三信号与锚点法

聊久会跑偏，三信号：

- **风格变了**（大白话突然拽术语）
- **前后矛盾**（前面说人手不足后面说充沛）
- **忘了要求**（说过不超 500 字后面动辄上千）

**解法：锚点法**——开头设项目卡片，**每隔两三轮重贴一次**：

> "提醒一下，项目设定还是这个（贴卡片），严格按这个来。"

**为什么有用？** AI 更在意离它最近的内容，**刚说的话权重远高于二十轮前的**。别指望它记住，主动提醒。**所以"聊长了就开新对话"——新对话 + 完整卡片，比硬掰快得多。**

![锚点法](/images/posts/2026-10-21-ai-94-锚点法.png)

## 六、什么时候不该拆

**满足任意一条就拆：**

- 输出超 1000 字
- 涉及 3 个以上环节
- 你自己也没底要边看边调

**别拆的活儿：** "帮我校通顺""这词什么意思""算下占比"——小任务套四步是形式主义。

## 七、完整实战演示

以年度总结为例，五轮：

**第1轮（框）：** 写 2025 部门总结，给分管副总看，只看结论。先只给目录框架（≤4 一级标题），不写正文。等我确认再继续。

**第2轮（确认+补料）：** 目录改三块：一、关键数据 二、三个突破 三、明年打法。动手前先问我 3 个你不知道但关键的问题。

**第3、4轮（填）：** 每轮重贴卡片。第3轮只写"一、关键数据"，数据贴在下面，一个数字不改，200 字内列表；第4轮只写"二、三个突破"，每个用"做了什么—带来什么变化"两句，不要形容词。

**第5轮（合+审）：** 下面是三部分全文。请：①统一语气；②删重复；③换分管副总身份指出三个最可能被追问的点。事实数据一字不改。

**五轮二十分钟，出来就能直接交。** 对比一句"帮我写完整总结"——**同样二十分钟，你还在跟正确废话较劲**。

## 📦 提示词模板盒子

### 模板 1：链式开局（第一环，通用）

```
我要完成的任务是：【一句话说清最终成品是什么】
成品给谁看：【读者及其关注点】
大致篇幅/规模：【多少字 / 多少页 / 多少部分】

现在请你只做一件事：
给我这个任务的【目录 / 方案框架 / 步骤清单】。

要求：
1. 只输出框架，不要写任何正文内容
2. 一级条目控制在【N】个以内
3. 每个条目后面用一句话说明这部分打算讲什么

输出后停下来等我确认，我确认前不要继续往下写。
```

### 模板 2：项目卡片（每一环开头都贴）

```
【项目卡片 · 请严格遵守】
- 我在做：【最终成品】
- 给谁看：【读者及关注点】
- 全文风格：【如：数据说话，不写形容词，段落不超过3行】
- 已确认的框架：【贴目录】
- 已完成的部分：【第几块】
- 本轮只做：【第几块】

请只处理"本轮只做"的部分，其余部分不要写。
```

### 模板 3：反向提问（不知道该补什么信息时）

```
接下来我要请你完成这个任务：【任务描述】

但在你动手之前，请先做一件事：
提出 3 个你需要知道、但我还没有告诉你的关键问题。
这些问题应该是"不知道答案就很可能做偏"的那种。

只列问题，不要开始做任务。我回答后你再动手。
```

### 模板 4：合稿统稿（最后一环）

```
下面是我们分【N】次完成的全部内容：

【粘贴全部内容】

请你做且只做以下三件事：
1. 统一全文的语气和用词习惯
2. 删除重复表达和啰嗦的过渡句
3. 检查前后是否有矛盾的地方（数据打架、说法冲突），
   如果有，单独列在最后告诉我，不要自行修改

严格禁止：
- 不得改变任何事实、数字、时间、人名
- 不得新增我没有提供的内容
- 不得删除任何一个数据点

输出：先给整理后的全文，最后附一段"发现的矛盾点清单"。
```

### 模板 5：换角色挑刺（质量把关环）

```
下面是我准备提交的内容：

【粘贴内容】

现在请你切换身份：
你不再是写作者，而是【接收这份材料的人，如：分管副总 / 甲方客户 / 评审老师】。

请以这个身份指出：
1. 三个你最可能当场追问的地方
2. 两个你觉得写得含糊、想让对方说清楚的表述
3. 一个如果我是你、最想删掉的段落，并说明为什么

只挑问题，不要帮我改。禁止说"整体不错"这类客套话。
```

### 模板 6：跑偏纠正（发现断链时）

```
提醒：我们的项目设定没有变，还是这个——

【重贴项目卡片】

但我发现最近几轮的输出出现了偏差：
【具体说明，如：语气变书面了 / 篇幅超了 / 和前面的说法矛盾】

请你：
1. 先用一句话复述你对本项目要求的理解，让我确认你没跑偏
2. 然后重做上一轮的内容，严格按项目卡片来
```
