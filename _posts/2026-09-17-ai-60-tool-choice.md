先说个常见循环。

**周一**装 Cursor 用两天"也就那样"；**周三**卸了装 Copilot 登录卡半小时；**周五**装 Qoder CN（原通义灵码）；**下周一** Claude Code 又火……一个月六个工具一行代码没写。

## 一、先分清：市面上的工具其实只有四类

看着二十几个名字，但**形态只有四种**。

**第一类：独立编辑器**（代表 Cursor、Trae、Windsurf）。本身完整编辑器。好比**装修好、家电配齐的厨房，搬进去就能做饭**。代价：得换软件。

**第二类：IDE 插件**（代表 Copilot、Qoder CN、CodeGeeX）。装 VS Code 里，编辑器还是原来那个。好比**现有厨房添台家电**，第59篇讲的。**优势：改变最小，退路最好走。**（注：Qoder CN 现在也出了独立 IDE，所以又跨第一类；本篇仍按它最常用、最省事的插件形态讲。）

**第三类：命令行工具**（代表 Claude Code、Gemini CLI）。没界面只有光标，但能动整个项目文件夹。好比**交代完就走的外包团队**，第58篇讲的。优势：跨几十文件批量改造别的真干不了；代价：过黑窗口关，且真会动你文件。

**第四类：网页聊天**（代表 ChatGPT、DeepSeek、豆包、Kimi）。啥都不装打开就用。好比**博学但看不见你厨房的顾问**。优势零门槛能问原理；短板不了解项目、代码手动搬。

## 二、六个维度横向对比（建议截图存手机）

最常被问的五款工具，按新手真正在意的六个维度拉平：

| 维度 | Cursor | Copilot | Trae/Qoder | Claude Code | 网页聊天 |
|---|---|---|---|---|---|
| **形态** | 独立编辑器 | IDE 插件 | 编辑器/插件 | 命令行 | 浏览器 |
| **上手难度** | 中 | 低 | **最低** | 中高 | 最低 |
| **要翻墙吗** | 要 | 要 | **不用** | 要 | 看产品 |
| **免费程度** | 有限免费 | 免费档/付费 | **基础版免费** | 付费 | 多数免费 |
| **懂你项目吗** | 懂（整个） | 懂（打开的） | 懂（整个） | **最懂（全文件夹）** | 完全不懂 |
| **最擅长** | 边写边改 | 灰字补全 | 中文+补全 | **跨文件批量** | 讲原理 |

**记四句结论就够**：只想快速试水→网页聊天；想在实际项目用→IDE 插件（改动最小）；打算长期认真做→独立编辑器（体验最顺）；手头老项目要大改→命令行工具（唯一能干这活）。

## 三、按场景选：五种典型情况

比起对比表，"我是哪种人"更能帮你决定。

**场景 A：完全不会代码，只想做个小东西玩**——做个记账页、抽奖工具、简历页。推荐**网页聊天+文本编辑器**或**VS Code+Qoder CN（原通义灵码）**，需求是单文件一次性不需要项目管理，工具越简单越好。**别装 Claude Code，杀鸡用牛刀还易被黑窗口劝退。**

**场景 B：职场人偶尔改点脚本/网页**——改公司官网文案样式、写数据处理小脚本。推荐**VS Code+Qoder CN（原通义灵码，或 Copilot）**，你不能换编辑器（团队用什么你用什么），插件是唯一不打扰别人的方案，改的都局部能力够。

**场景 C：系统学编程边学边练**——推荐**网页聊天（学原理）+ IDE 插件（做练习）**，唯一建议用两个。遇"闭包是什么"用网页讲，写作业用插件。**提醒：学习别开太猛补全**，先自己写。

**场景 D：有成型项目要持续开发**——推荐**Cursor 或 Trae**，项目一大需要"改这功能帮我把相关几个文件都调了"，独立编辑器整合度最好。

**场景 E：接手别人烂摊子要大改**——推荐**Claude Code（命令行）**，这是它主场也几乎唯一能干这活的，"统一整个项目日期格式""给所有函数补中文注释"跨几十文件插件做不了。**前提：先备份整个文件夹**，第58篇强调过。

## 四、钱怎么花：免费到底能干到什么程度

**完全免费能做的事（0 元）**：网页聊天、Qoder CN 个人基础版、CodeGeeX、Trae 基础版 都免费（Copilot 也有个人永久免费档，重度 Agent 模式才付费），**结论：不花钱能完成模块四 90% 练习。**

**什么时候值得付费**，满足任意一条：①连续两周每天用且额度不够；②做产生收入活；③免费工具卡住（如跨几十文件批量）。都不满足别买，新手"先买会员逼自己学"多是心理安慰。学生有学校邮箱一定申 GitHub 学生包，Copilot 免费用。

## 五、三个问题的决策流程（三分钟锁定工具）

前面都记不住就记这个，三个问题问完有答案。

**问题一：现在要"学"还是要"做"？**——学（搞懂概念）→ 网页聊天，到此结束；做（出能跑的东西）→ 进问题二。
**问题二：能不能换编辑器？**——不能换（公司规定/团队统一/用惯了）→ IDE 插件，到此结束；能换→进问题三。
**问题三：改"一处"还是"整个项目"？**——一处（改函数、加页面）→ Cursor/Trae；整个项目（跨几十文件批量）→ Claude Code。

**就三个问题，认真回答工具就定了。**

## 六、被忽略的真相：你不用只选一个

前面都讲"选一个"，但现实熟手基本组合用。典型日常：

| 时间点 | 用什么 | 干什么 |
|---|---|---|
| 想不明白某概念 | **网页聊天** | 展开讲，多问几轮 |
| 日常写代码 | **IDE 插件/Cursor** | 补全、局部改、解释代码 |
| 偶尔大改 | **Claude Code** | 跨文件批量 |

**为什么能并存：它们互不冲突**，铁律：**同一层级只留一个**，别让几个补全插件打架。**新手先只用一个，用满两周再加第二个。**

---

## 七、换工具的成本，比你想象的低

很多人纠结选型怕"选错浪费时间"。**定心丸：换工具成本极低**，你学的不是工具是提问方式。回顾系列五条（一次一件/写清要什么给什么/改前先解释/报错整段贴/选中再问），**在哪工具都成立**。工具是壳，**提问能力才是资产**，换工具能力不掉。所以：**别纠结，今天挑一个开始，用错大不了换，真正的浪费是一个月光挑不写代码。**

## 提示词模板盒子

> 以下模板直接复制，方括号换成你自己的。

**模板一：让 AI 帮你做个性化选型（对应第五、三节）**

```
我需要选一个 AI 编程工具，请帮我判断。我的情况：
- 编程基础：[完全不会 / 会一点 / 有经验]
- 电脑系统：[Windows / Mac]
- 能否访问国外网站：[方便 / 不方便]
- 预算：[只用免费 / 每月几十块]
- 想做的事：[具体，例如"做几个小网页玩""改公司脚本""维护老项目"]
- 能不能换编辑器：[能 / 不能，原因……]
请给我：1）最推荐的工具及理由（三条内）；2）一个备选及什么情况换它；3）明确告诉我不该选哪个及为什么；4）上手第一步具体做什么。
```

**模板二：试用评估与迁移（对应第六、七节）**

```
场景A｜试用三天后自查：
我用[工具名]三天了，帮我评估要不要继续。
使用情况：每天用多久 / 主要做什么 / 好用的地方 / 别扭的地方 / 遇到的问题。
请判断：1）问题是工具局限还是我用法不对；2）用法问题给三条立刻可执行建议；3）确实不合适推荐替代。

场景B｜迁移到新工具：
我原用[旧工具]现换[新工具]。旧工具常用操作：
1. [例如 Ctrl+K 唤起对话] 2. [例如 @ 引用文件] 3. [例如选中代码问]
请：1）逐条告知新工具对应什么（快捷键/位置）；2）列新工具有旧没有的3个功能；3）列3个和旧习惯冲突处提醒我。
```

**模板三：跨工具通用起手式（换到哪都能用，对应第七节）**

```
你好，我完全不会写代码。开始前请先记住我三条要求：
1. 每次只做我说的这一件事，不顺手改别处；
2. 给代码同时用中文注释解释每段干什么；
3. 我需求不清楚先反问我，不自己猜着做。
明白回复"明白"，我们开始。
```

## 一页速查：三条选型铁律

1. **同一层级只留一个**——三个补全插件打架比没有还糟

3. **选型不超三分钟**——换工具成本半小时，纠结成本一个月
